**Lirik-Python-All-Song** adalah sebuah proyek *open-source* sederhana untuk memutar lirik lagu favorit kamu langsung di dalam terminal dengan gaya animasi *synchronized lyrics* dan *progress bar* ala Spotify Premium! 

> ✨ **Keunggulan:** Semua lirik lagu berada dalam satu repositori, dan kamu hanya memerlukan **1 file Python saja** untuk mengeksekusinya!

---

## 🚀 Fitur Utama

* 🟢 **Spotify Theme:** Tampilan teks berwarna hijau neon dan putih kontras khas Spotify.
* ⏳ **Dynamic Progress Bar:** Animasi *loading bar* yang berjalan otomatis menyesuaikan jeda antar lirik.
* ⌨️ **Typewriter Effect:** Efek mengetik per karakter yang membuat transisi lirik terasa lebih hidup dan estetik.
* 🧹 **Auto Clean Terminal:** Terminal otomatis dibersihkan secara berkala agar tampilan tetap rapi dan fokus.
